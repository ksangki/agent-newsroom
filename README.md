# 에이전트 편집국 — AI에게 글을 맡긴 뒤, 사람은 무엇을 책임지는가

> **초안 판본 (v1.2.2) — 저자가 원고 전문을 검토하기 전에 공개한 판본입니다.** 내용은 바뀔 수 있습니다.

AI 에이전트에게 블로그 초안을 맡기면 하루 한 편을 내는 일은 쉬워진다. 그렇다면 사람은 무엇을 확인하고 무엇을 책임져야 하는가. 이 책은 "글을 만드는 비용이 0에 가까워지면, 블로그의 가치는 어디로 옮겨 가는가"라는 질문을 들고, 지금 꾸릴 수 있는 운영 체계 — **에이전트 편집국**(역할 분담과 사람이 맡는 일, 사실 검사, 읽기 좋은 글을 가려내는 문체 기준, AI가 한 일과 사람이 확인한 일을 밝히는 표기, 쌓인 글의 관리) — 를 정리하고, 다음 블로그에 대한 전망은 반증 조건이 붙은 **가설 카드**로 남긴다.

저자가 DEVOCEAN에서 만들어 운영하는 AI 필진 DEVOTEE의 실제 운영 방식과 한계가 사례로 나온다. DEVOTEE는 모범 사례가 아니며, 3장에서 이 책이 권하는 설계와 나란히 놓고 비교한다.

## v1.2.0~v1.2.2에서 달라진 것

외부 편집 검토서를 저자 결정으로 전부 반영했다 — 논리·단정 수정(Pew 8%/15%는 방문 단위 관찰 분석, 인용은 클릭 다음 단계가 아닌 별도 경로로 그림 10-1을 새로 그림, 보장 문구 대신 발행 기능의 실행 조건), 문체 정리, DEVOTEE 설명을 3장에 모으고 권하는 설계와 실제 운영을 표 3-2로 비교, 새 부제와 1·5·6장 제목, 새 표지와 본문 삽화 6점(분위기 그림, 자료 도식 아님), 부록 C. 장별 사실 검증과 수락 검수를 다시 거쳤다.

## 이 책은 어떻게 만들어졌나

이 책의 초안은 에이전트 하네스로 만들었다 — 리서치(웹·논문·커뮤니티), 계획(저자 승인), 장 묶음별 저술, 장별 사실 검증, 그림, 편집 통합, 교정 패스(원고 CI·writing-deslop), 앞 단계와 맥락을 공유하지 않는 수락 검수. 저자는 주제·방향·관통 질문을 정하고, 계획을 승인하고, 인터뷰에 답하고, DEVOTEE 코드의 공개 서술을 허락했으며, 판마다 무엇을 고칠지 정했다. 표지와 삽화는 외부 검토자가 이미지 생성 도구로 만든 시안을 저자가 채택했다. 자세한 내용은 책의 서문과 부록 C에 있다.
